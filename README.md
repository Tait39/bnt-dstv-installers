# B.N.T DSTV Installers

A responsive two-page business website for B.N.T DSTV Installers, serving Gqeberha (Port Elizabeth) and surrounding suburbs.

## Stack
- React + Vite
- React Router
- Lucide icons
- Custom responsive CSS

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Contact configuration
The business phone, WhatsApp number and email are currently configured in `src/App.jsx`.

The enquiry form opens a pre-filled WhatsApp message for the visitor to review and send. It does not store submissions or automatically send messages.

## Important content notes
- The business is presented as an independent installer; no DStv accreditation or official partnership is claimed.
- Enquiries are welcome 24/7, but actual appointment availability is confirmed directly.
- Service descriptions should be reviewed with the business owner before public launch.
- Replace stock imagery with genuine business photographs when available.
- The domain is purchased and owned separately by the client.
